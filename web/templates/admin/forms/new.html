Special fields

Redirects, spam protection, and what Formlander saves.

Formlander saves every field your form sends, with any name. There is no schema. These names are special: Formlander reads them and does not save them.

_success_url
Where the visitor goes after a successful submit. Use a full URL on one of the Allowed Origins, for example https://example.com/thanks. Without it, the visitor sees a Formlander thank-you page.
_error_url
Where the visitor goes when the submit fails, for example a failed captcha. Same rules as _success_url. Without it, the visitor sees a Formlander error page that explains the problem.
__fl_hp
Honeypot. A hidden, empty text input. People leave it empty, bots fill it, and Formlander marks those submissions as spam. The starter templates include it.
cf-turnstile-response
Added by the Turnstile widget when the form has a captcha profile. You don't write it yourself.
<input type="hidden" name="_success_url" value="https://example.com/thanks">
<input type="hidden" name="_error_url" value="https://example.com/oops">
<input type="text" name="__fl_hp" style="display:none" tabindex="-1" autocomplete="off">

With the JavaScript SDK, the page doesn't reload: the SDK shows the result in place, or follows _success_url and _error_url itself. Read the integration docs →
