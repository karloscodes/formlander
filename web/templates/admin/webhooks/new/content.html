Where each submission goes.

Only you see it. It tells your profiles apart.

Formlander sends each submission here as a POST request with a JSON body.

Services protect a webhook in different ways. Paste what yours shows:

  • A key alone, like abc123. Formlander sends Authorization: Bearer abc123.
  • A header line, like X-API-Key: abc123. Formlander sends that header.
  • Nothing. Many services (Zapier, Make, Slack) put the secret in the URL and need no key.
More options : a signature for your own server, more headers

For a receiver that you wrote yourself. It is not the access key of a service. Each request gets an {{ .SignedBy }} header with the HMAC-SHA256 of the body in hex. Your server computes the same value with this secret and compares the two.
