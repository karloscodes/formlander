How to get your keys

  1. Sign in to the Cloudflare dashboard and open Turnstile. A free account works.
  2. Click Add widget. Add every domain that shows your forms, for example example.com. Keep the widget mode on Managed.
  3. Create the widget. Cloudflare shows a Site Key and a Secret Key.
  4. Paste the Secret Key below. Put the Site Key in Site Keys, with the same domain.

Formlander uses it to check each captcha with Cloudflare. It never appears in your form code.

Site Keys (Multi-Domain)

Configure different site keys for different domains

Format:

  • • host_pattern: Domain or wildcard pattern (e.g., "example.com", "*.example.com")
  • • site_key: Turnstile site key for that domain
  • • System matches the embedding domain against patterns to select the correct site key
